**🍰 Sweet Delight Bakery**

A colorful and user-friendly bakery website designed using HTML and CSS. The project showcases bakery products, images, information about the bakery, and a contact page through a simple multi-page website.

**📌 Project Overview**

Sweet Delight Bakery is a front-end web development project created to demonstrate the fundamentals of building a structured and attractive bakery website using HTML and CSS.
The website contains multiple pages connected through navigation links, along with bakery images, product sections, a gallery, and a contact form.

**✨ Features**

🏠 Home page with bakery introduction

🎂 Cakes and bakery products page

🖼️ Image gallery

📖 About Us page

📞 Contact page with contact form

🎨 Custom CSS styling

🔗 Multi-page navigation

📱 Clean and user-friendly layout

🎥 Bakery video section

🖼️ Bakery images and visual content

**🛠️ Technologies Used**

CSS3

**🌐 Website Pages**

🏠 Home

Introduces Sweet Delight Bakery and provides navigation to the other sections of the website.

🎂 Cakes

Displays different cakes and bakery products.

🖼️ Gallery

Showcases bakery-related images in a visual gallery.

📖 About

Provides information about the bakery.

📞 Contact

Contains contact information and a contact form for visitors.

**🚀 How to Run**

No installation is required.

Download or clone this repository.

Open the project folder.

Double-click index.html.

The website will open in your web browser.

Use the navigation menu to explore the different pages.
